## 二、报价（本期）

计费人天 = 本期表中未标「工作量忽略」且不为 `-` 的人天之和。

忽略不计：沟通 2 + 文档 0.5 + S1 1 + 部署 2 + B18 0.5 = **6 天**。

后置不计：Agent 平台 AG1~AG7 = **7.5 天**（见第四节，不计入本期）。

### 2.1 按板块


| 项目                      | 计算                          | 数值        |
| ----------------------- | --------------------------- | --------- |
| 沟通 + 文档                 | 忽略                          | 0 天       |
| 架构与梳理（S1~S4）            | S1 忽略；S2 1 + S3 1（S4 并入 S3） | 2 天       |
| Agent 数字员工协作平台           | 后置，见第四节                     | 0 天       |
| 业务功能（B1~B18，**B5 按 0**） | 7 + 2 + 7；B18 赠送            | 16 天      |
| 部署收尾                    | 优惠免掉                        | 0 天       |
| **计费人天**                | 2 + 16                      | **18 天**  |


业务功能分项验算：

- B1~B9（增量/修复/隐藏）：0.5+1+2+1+0+0.5+0.5+0.5+1 = **7**
- B10（C 端套餐与卖价，新增）：**2**
- B11~B17（php-server 存量迁新后台，B18 赠送不计）：2+0.5+2+0.5+0.5+1+0.5 = **7**
- 小计 **16**


### 2.2 按性质


| 性质     | 人天       | 占比   | 对应项                     |
| ------ | -------- | ---- | ----------------------- |
| 平滑迁移   | 8 天      | 44%  | S2、B5、B11~B17（B18 已赠送） |
| 新增     | 5 天      | 28%  | B3、B4、B10               |
| 迁移+优化  | 5 天      | 28%  | S3、S4、B1、B2、B6、B7、B8、B9 |
| 梳理/其他  | 0 天      | 0%   | 部署已免；沟通/文档/S1/B18 已忽略   |
| **合计** | **18 天** | 100% |                         |


验算：8 + 5 + 5 + 0 = 18。
