# 房型套餐（B4）需求说明

> 状态：需求草案（待海豚系统价单样本对齐后细化）
> 关联：3.0 PRD B4 / 后台迁移清单 R06

## 1. 定位

房型套餐是一份**独立的「价单」**，与「日历房价（B3）」**无关联**，不参与线上自动算价。

- 参考竞品：海豚系统（账号/网址由 @Wally.W 提供）。
- 用途：向 B 端客户展示某酒店可售的「打包套餐」及其牌价。
- 下单：客户点击预订后，**仅生成预定意向单**；最终价格由后台人工核对并**手动新建正式订单**。

## 2. 套餐展示内容

套餐详情页需完整展示以下信息（以海豚系统「最全展示」为标准，具体字段开发时对齐）：

- 晚数（入住晚数）
- 房型组合（套餐对应的房型）
- 餐标（膳食计划）
- 交通（接送方式）
- 福利（赠送项 / 权益）
- 第三人计价规则
- 儿童计价规则

## 3. 时间与价格

- 同一酒店套餐允许配置**最多 6 个**适用时间段，每个时间段对应各自的打包价。
- 支持多时间段并存展示。

## 4. 定价与下单逻辑

- **不做线上自动算价**：系统仅展示后台录入的牌价，避免算价错误。
- 客户点击「预订」→ 生成预定意向单，不直接生成正式订单。
- 正式订单由后台运营人工核对价格后手动新建。

## 5. 范围边界

- 与日历房价（B3）解耦，两者互不影响。
- 本次不实现套餐的线上价格计算。
- 套餐数据模型与后台录入页面另立设计（待海豚系统价单样本对齐）。
