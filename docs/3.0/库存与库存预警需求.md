# 库存与库存预警（B5）需求说明

> 状态：需求草案
> 关联：3.0 PRD B5 / 后台迁移清单 R02、R04

## 1. 定位与关系

- **控房管理 = 马尔代夫控房**：保持现有打包形式（房型 + 交通 + 餐食），继续沿用独立控房表（`room_control`），不与普通库存表融合。
- **库存 / 库存预警 = 非马尔代夫目的地**（越南、泰国等）。
- PHP 旧版库存/预警基本是半成品，实际没怎么使用；旧「库存」是手工维护的可售量台账，旧「预警」只是库存图例/提示语配置。

## 2. 库存需求

- 按**房型**管理空房数量。
- 提供**日历视图**，运营可按房型、按日期手动设置空房数量。
- 库存是平台手工维护的「可售量」台账，不接酒店实时库存，也不参与下单扣减（除非后续另行确认）。

## 3. 库存预警需求

- 支持设置库存预警**阈值**。
- 当某房型在某天的剩余数量**低于阈值**时，日历视图中对应日期**自动变色提示**。
- 预警为日历内的可视化提示，本次不包含自动消息推送（如需推送另行确认）。

## 4. 数据现状

- `snake_stock`：`room_id + room_time + stock + sale + ...`，按房型按天。
- `snake_range`：库存预警图例/提示语配置（`content / info / range / color`，按用户 `uid`）。
- 两表当前数据量极小（stock 23 条、range 3 条），可视为待重新设计使用。

## 5. 待办 / 待确认

- [ ] 预警阈值是「酒店级」还是「房型级」统一/分别设置。
- [ ] 是否需要在库存日历里区分「空房总量 / 剩余可售量」。
